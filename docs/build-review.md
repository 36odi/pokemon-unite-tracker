# 構成の振り返り（v5.69 / SW v95）

対戦記録・構成別の成績・ラボの計算をつなぐ機能。確認用の架空データやローカル用の案内バーは本番コードへ含めない。

## 実装した内容

- 履歴の「この構成で計算」：記録したわざ・もちもの・メダルを攻撃側へ渡す。
- 記録したメダルの中身・レアリティを直接計算。現在のプリセットを変更しても影響しない。
- 未記録のレベル・G・相手を計算用の条件として明示。初期値はLv9/G30、相手は空欄。
- ポケモン別詳細：「成績」「使用構成」「データ・計算」。未使用のポケモンでもデータへの入口を使用可能。
- 構成の集計は、わざ・もちもの（順不同）・バトルアイテム・メダルの中身で分け、試合数・勝敗を表示。
- もちもの比較：Aの装備・G・発動状態を固定。Bは現在の攻撃側。レベル・メダル・相手・選択わざは共通で再計算。
- 成分ごとの数値・差・比率と、もちものの発動1回分を別表示。

## 範囲

元の対戦記録やメダルプリセットは書き換えない。計算は既存ラボのデータと対応範囲を使用。
過去バージョンの再現、コンボ合計、急所確率・攻撃間隔を含む総合順位付け、名前付き構成の永続保存は含まない。
通常表示と比較は `labEvaluateComponent` を共有。追加効果の発動量をわざへ自動加算しない。
