# 計算条件の保存・共有／調整前後の分析（v5.70）

「海外のポケモンユナイトサイトを収集」チャットの最終画面案3・6に接続。
保存一覧を中心にし、計算の入力欄は「条件を編集」で展開する。

## 計算条件

- 攻守のポケモン・レベル、各もちもののG、発動状態・追加入力、攻撃側のスタック・回復対象、わざ・強化段階、メダル10枚の中身・レアリティ、比較Aを保存。Bは現在の攻撃側。
- 保存先は利用者別のlocalStorage。ゲスト・各アカウントを分離し、端末間の同期・ゲストからアカウントへの自動移行は行わない。
- 名前・自分用メモは保存一覧だけに保持。共有リンクのフラグメントには入力条件だけを含め、アカウント・対戦記録・保存名・メモ・メダルセット名を含めない。
- 受信した条件は確認画面を経て読み込み、一覧には自動保存しない。未対応項目は案内して読み込みを止め、別項目へ置き換えない。
- メダルは保存時のスナップショット。現在のプリセットを変更しても保存条件の計算は変えない。
- 計算データの内容から識別値を作り、保存時と異なる場合は現在のデータで再計算する旨を案内。過去のゲーム版を再現する機能ではない。
- 外部共有サーバー・新しいDBテーブル・クラウド書き込みは追加しない。対戦記録・メダルプリセットは変更しない。

## 調整前後

- 全シリーズの記録を既存の全件取得で読み込む。BOTを含む読み取り用キャッシュを分け、既存の集計設定を変えずに新画面のBOT切替に対応。
- 前は「境界−日数以上、境界未満」、後は「境界以上、境界＋日数未満」。境界はJSTの公式日時。日時不明・未来日時を除外し件数を表示。
- 前後7・14・28日、対戦形式、実際のランク、同じ構成、個別のわざ・もちもの・バトルアイテム・メダルの中身で絞り込む。
- ランクは既存の直前レートによる判定と手動訂正を共用。わざ等の未記録、メダルの中身が異なる記録を別条件として扱う。
- 勝敗・勝率差（ポイント）、各スタッツの平均と個別対象数、平均対象外・未記録数、ランク・構成・形式の内訳を表示。片側に記録がなければ比較不能と明示。
- 調整後の指定期間が未終了の場合は警告。前後差は調整の因果効果と断定しない。
