# ラボ計算の確認結果（2026-10-09）

## 今回の変更

ステータス計算とダメージ計算で同じ計算処理を使い、以下の一時効果を個別にON/OFFできるようにした。初期値はOFF。もちものを外すと解除する。攻撃側・防御側の設定は独立している。

|もちもの|G1〜9 / G10〜19 / G20〜40|条件|
|---|---|---|
|ふんばりベルト|防御・特防 +12 / 20 / 28%|妨害を受けた後の3秒間|
|かるいし|移動速度 +10 / 15 / 20%|戦闘から離れて5秒後|
|こだわりスカーフ|移動速度 +30 / 35 / 40%|通常攻撃の条件を満たした後の3秒間|
|れんだスカーフ|攻撃速度補正 +15 / 20 / 25ポイント|通常攻撃3回命中後の5秒間|
|エナジーアンプ|与ダメージ +7 / 14 / 21%|ユナイトわざ使用後の効果中（通常4秒）|

ONは発動中の瞬間の計算で、経過時間・再発動待ち時間は再現しない。エナジーアンプは回復・シールドには適用しない。既存のじゃくてんほけんは被ダメージスタック数0でOFFとなる。

レスキューフードは自己回復に適用しない。味方への回復・シールドは17 / 20 / 23%増加。おおきなねっこは自己回復のみ10 / 15 / 20%増加。対象選択を追加したが、わざ自体が指定対象に使えるかは利用者が判断する。

## 数値と計算式

- 基本ステータス：101種 × 15レベル × 6項目 = 9,090値を取得したUnite-DBデータと照合し、差分なし。
- もちもの：既存34種 × G1〜G40の固定ステータスを照合。7種・100値を修正。確認値は `data/held-item-stats.json` に保存し、再生成時にも適用する。
- わざの係数：リポジトリ内の参照CSVとの照合は1,774行一致。全わざの最新ゲーム内実測や最新外部データとの再照合を完了したという意味ではない。

|修正したもちもの|変更値の数|例|
|---|---:|---|
|がくしゅうそうち|40|G30 HP240→360、G40 HP280→420|
|れんだスカーフ|20|奇数グレードの攻撃速度上昇値|
|いやしのかんむり|17|奇数グレードのHP・攻撃への割り当て|
|こだわりスカーフ|8|G40 攻撃速度8.7→8.75|
|エナジーアンプ|5|G40 待ち時間-5.2→-5.25%|
|するどいツメ|5|G40 急所率2.3→2.35%|
|かいがらのすず|5|G40 待ち時間-5.2→-5.25%|

Unite-DBの各項目の `initial` / `increment` / `skip` / `start` / `initial_diff` と同サイトのグレード計算処理を照合した。G31以降はG30の値に増分を半減した成長値を追加する。表示用の小数桁丸めをデータ値に適用しない。

割合補正は、もちもの・個別メダル・ゴールによる固定加算を含めて計算する。色セットの割合補正は基本値に対する加算として分離する。

```
(基本値 + 固定もちもの補正 + 固定メダル補正) × (1 + 割合補正の合計)
  + 基本値に対するメダル色セット補正
```

ステータスの小数を途中で丸めず、表示は小数2桁まで。わざの基礎ダメージは係数・レベル補正・固定値を合算して切り捨て、防御による軽減後にも切り捨てる。エナジーアンプは軽減後のダメージに適用して切り捨てる。同じもちものを複数枠に選んだ場合は最初の枠だけを使う。

## 確認範囲と制約

- 通常攻撃速度は補正量。ポケモン固有の攻撃間隔・攻撃回数の計算ではない。
- 移動速度は減衰前の値。ゲーム内の速度上限・減衰は再現していない。
- もちもの自身の追加攻撃・回復・シールド、急所発生、ポケモン固有の能力変化など、戦闘中の全効果を再現するものではない。
- わざデータに含まれない条件や特殊な参照ステータスは網羅していない。ゲーム内実測による全わざ・全組み合わせの保証はない。
- ダメージ種別の判定など既存の制約があるため、資料との一致を「すべての実ダメージが正しい」とは扱わない。
