# 特性・わざの説明表示

対象は現在のラボ103体。進化前後を含む特性128件、わざ691件の主な効果を日本語で要約し、出典の説明行と対応づけた。

## 表示

- 特性：ステータス計算・ダメージ計算・レシオ一覧で同じ説明を表示する。特性名、発動条件、進化前後の違いを分け、既存の数式も残す。
- わざ：レシオ一覧のわざ名の直下に説明を置き、待ち時間・レシオが続く。強化後も主な効果の要約を参照する。説明だけで全仕様や全強化差分を網羅したものではない。
- サンダース・ブースターに既に用意した説明と条件注記は優先して保持する。
- 能力上昇、カウンター、発動条件などを自動的に計算へ加算しない。説明用の行は数式を持たず、既存の計算用データ・保存条件・対戦記録を書き換えない。

## 出典と管理

元データは2026-10-22に取り込んだ[レシオシート](https://docs.google.com/spreadsheets/d/13m4W2oLU__PPKQrHVPRqBHopQbXBggSJCdse6BXAqys/edit)と、その正本CSV `data/unitedb_ratios.csv` の `true_description`・`notes`。要約の確認日・CSVのSHA-256・出典成分キーを生成データへ保存する。日本語Wikiは一部を確認したが取得制限がかかったため、追加の取得を停止した。全ポケモンの最新Wikiとの一括照合を実施済みとは扱わない。

原稿は `data/lab-passive-descriptions.txt` と `data/lab-move-descriptions.txt`。数値列を推測で埋めず、出典のない説明を生成しない。別形態で同じわざを使う場合は、明示した共有先を使う。

再生成：`node tools/build_lab_descriptions.js --apply`

検証のみ：`node tools/build_lab_descriptions.js`

生成先は `lab_descriptions.js`。新ポケモン・新わざの説明不足、重複、原文説明のないキーを検出する。キーの照合だけでは意味の一致は保証できないため、出典の説明が変更された際には要約も照合して更新する。
