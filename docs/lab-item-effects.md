# もちもの自身の追加効果（2026-10-11）

ステータス計算・ダメージ計算で、装備した以下15種の発動量を個別にON/OFFできる。初期値はOFF。外すと解除する。同じもちものは最初の枠だけ使用する。ダメージ計算では攻撃側と防御側を独立して設定し、反射・追加攻撃は反対側の防御・特防を参照する。

数値は **G1〜9 / G10〜19 / G20〜40**。参照する攻撃・特攻・最大HPは、設定したもちもの・メダル・一時効果を反映した合計値。

## 入力と表示

- ちからのハチマキ：発動直前の残りHPを使う。ステータス計算はHP値を入力。ダメージ計算は相手側の設定の最大HPと残りHP割合を使い、割合の初期値は100%。この効果の上限は野生ポケモン用ではない。
- きあいのハチマキ：回復直前の自分の残りHP割合を入力する。25%以上・HP0は発動しない。**その瞬間の1回分**だけ表示する。回復で不足HPが変わるため、3回分を単純に掛け算しない。
- いやしのかんむり：物理の通常攻撃でHPへ直接与えたダメージを入力する。わざ・特殊攻撃・シールド・もちもの自身の追加ダメージを混ぜない。発動可能な通常攻撃かは利用者が判断する。資料上、一部のマークも通常攻撃の属性を継承するため、対象となる分は入力値に含める。
- 必須の入力が空欄・不正なら数値を推定せず入力案内を表示する。
- こだわりメガネは特殊、他の追加ダメージ5種は物理として軽減する。すりぬけスプーンは特殊ダメージに適用する。
- 回復は自己回復としておおきなねっこを適用する。シールドは自分と味方を別表示し、レスキューフードは味方分だけに適用する。わざの回復対象選択とは独立。
- 基礎の発動式で切り捨て、ダメージは防御・特防で軽減後に切り捨て、ONのエナジーアンプで増加後に切り捨てる。回復・シールドも補正後に切り捨てる。

## 範囲と制約

**各もちものの発動量を結果欄へ別表示する。わざの各ヒットへの自動加算や、回復・シールドの被ダメージからの自動差し引きは行わない。** 通常攻撃1回のヒット数ともちものの発動回数は一致するとは限らない。ONは発動条件を満たした場合の値で、条件の成立、待ち時間、時間経過、急所の発生、移動によるチャージ、複数人のシールド重複は自動判定しない。シールドの残量・特殊専用の吸収・ゴール中断防止を使った戦闘シミュレーションではない。

回復表示は不足HPによる上限適用前の効果量。たべのこし等は1秒分のみ。攻撃・特攻・HP等への固定ステータス補正は、追加効果をOFFにしても反映される。ポケモン固有の特殊処理、ダメージ・回復を増減するすべての戦闘効果を網羅せず、全組み合わせのゲーム内実測は未実施。
