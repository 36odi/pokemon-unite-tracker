## なぜ直接編集したか

これまでの正本（unite-db を元にした2冊のスプレッドシート）の更新が止まり、11/12の正確な数値が入手できない。サービス終了（2027-03-23）の発表で次回の更新も不明なため、ユーザーの許可を得て、正本CSV・原文メタデータ・説明原稿・詳細補足・攻撃速度の編集元を直接書き換えた。

`build_lab_skills_from_keys.js` と `lab_detail_notes.js` は正本CSVのハッシュを照合して停止する設計のため、`lab-reference-metadata.json` と `lab-detail-notes.json` の `meta.ratioSha256` も新しいCSVに合わせた（反映前は `6213e882…`）。英語の原文（CSVの説明列・`evidence`）は unite-db 当時の記載のまま残している。

## 推定方法

公式が「ダメージ◯％増加／減少」とだけ記載した項目は、係数・固定値・レベル係数の3つに同じ倍率を掛けた（全レベルで最終値がちょうど同じ割合だけ変わる）。小数第2位で四捨五入。変更前後の具体値が記載された項目は、その値をそのまま採用した。

## 反映していないもの

- ストリンダー「オーバードライブ：電気の連鎖による追加ダメージ 8％〜5％減少」：対象の数値成分（「でんきの音色（反響）」と推定）と幅の意味が告知から確定できないため、ユーザー判断で数値は据え置き。
- 不具合修正（モルペコ スパーク+、バシャーモ オーバーヒート）：ラボの計算対象外。

## 検証

- ラボデータの差分は意図した27行のみ（ステータス・もちもの・メダルは不変）。説明データは11か所、公開ページは影響した10体のみ更新。
- 生成器（スキル・ステータス・説明・攻撃速度・公開ページ）の再実行で差分ゼロ。適用ツールの再実行は全35項目が適用済み。
- テストの旧値（パンクロック5段40%、カイリュー回復300、ヌメルゴン3%）を新値に更新。非ブラウザの全テストと、ブラウザの説明31・公開ラボ959・攻撃速度225・SW更新4項目が通過。
- `lab-reference`・`ratio`・`lab-ratio-effects`・`lab-detail-notes` のブラウザテストは、変更前のHEAD（cf92dec）でも同じ箇所で失敗する既存の不一致（アイアンヘッド、バランス型の一覧、特性の種数）で、今回の変更とは無関係。

## 今後シートを同期する場合

正本シートが正確な値で更新されたら、シートを優先して同期する。同期するとこのファイルの数値変更は上書きされる（`apply_official_patch_20261112.js` は値が想定外になるため中止し、上書きを防がない）。シートが11/12前の値のまま同期される場合は、同期後に本ツールを `--apply` すれば推定値を再適用できる。
