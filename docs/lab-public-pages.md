# ログイン不要ラボとポケモン別ページ

第5段階のローカル実装：2026-10-26 JST。公開・検索エンジン登録は未実施。

## 入口とURL

- `lab/`：JavaScriptなしでも103体のリンクを読める一覧。名前検索は補助機能。
- `lab/pokemon/<ポケモン名>/`：既存の保存キーと同じ名称を使用し、URLではエンコードする。各ディレクトリの`index.html`を直接配信する。GitHub Pages用の404転送やサーバー側の書き換えに依存しない。
- `?lab=<ポケモン名>&tool=ratio|calc|dmg|medal`：既存ラボの計算画面。未指定・不正なtoolはratio。存在しないポケモン名は未選択として明示する。
- 通常の`#conditions=...`は従来どおり。閲覧ラボから作る条件共有だけは`?lab=<攻撃側>#conditions=...`とし、受信時もログインやゲスト開始を行わない。

ログイン画面に「ログインせずにラボを見る」を追加。ポケモン別ページから各計算画面へ進め、レシオ一覧から静的ページへ戻れる。

2026-10-26の追修正：画面内のリンクはすべて対象の`index.html`まで明示する。ディレクトリURLはcanonical/サイトマップに残すが、ローカルファイルを直接開くときにフォルダー一覧へ進まないよう区別する。一覧への戻り・計算画面への入口も同じ方式。`file://`で実際のリンク操作を検査済み。

レシオ本文は、すべてのわざ・＋版・通常攻撃・特性で「効果・条件の説明」を開くと説明が読める。追加注記の有無によって開閉操作を変えない。説明が未収録ならその旨を示す。計算式と待ち時間、式に付随する未反映・未確認の注意は初期表示する。本文・数値を削らず、句点での改行、15pxの本文、1.85倍の行間、通常版/＋版の余白で読み分ける。静的ページでも標準の開閉操作を使い、JavaScriptなしで説明を開ける。ユナイトわざの共通強化の説明も開閉式。

閲覧用のポケモン・タブ変更はHistory APIでURLへ記録し、戻る・進むで再表示する。閲覧URLは計算条件全体の保存ではない。レベル・装備・相手などを渡す場合は既存の条件共有を使う。

## アカウント・保存の分離

`LAB_PUBLIC_MODE`は認証用ライブラリより先に決定する。閲覧時はSupabaseライブラリと認証クライアントを起動せず、利用集計も開始しない。対戦記録・プロフィール・ログアウトなどの操作は表示しない。

既存のguestMode、移行待ち、対戦記録、メダル、条件一覧、認証トークンは読み替え・削除しない。閲覧中のメダルプリセットは既存の保護モジュールをメモリー上の保存先で使用する。計算条件の保存一覧もメモリーだけに保持し、ページ移動・再読込で消えることを表示する。通常利用時の永続保存と共有形式は維持。

ブラウザー検査では、ゲスト・移行待ちとアカウント相当の保存内容を入れた環境、および新規環境を使用。閲覧・計算・一時保存・共有読込による端末保存の変更0、外部リクエスト0を確認した。実アカウントへのログインや実DB書込は行っていない。

## 静的生成と更新

`node tools/build_lab_pages.js`で、一覧1ページ・ポケモン103ページ・sitemap.xml・robots.txt・生成元一覧の計107ファイルを生成する。元データ全体を作る`gen_lab_data.js`は実行しない。

基本値は既存`computeStats()`、式・説明・＋版補完は既存`ratioRender()`と`labUpgradeRows()`等をそのまま使う。新しい数式や未確認値の代入はない。静的取得でLv1〜15の基本値、わざ・特性の説明と式が読める。割合の単位、短縮率、最終更新日の意味、未反映の条件は既存表示に従う。

更新手順：

1. 元データ、共通処理、レシオ表示、資産版などを変更したら上記コマンドで生成する。
2. `node tools/build_lab_pages.js --check`で生成済みファイルと現在の元データの一致を確認する。
3. 必要な範囲で`tests/lab-public.browser.test.js`を実行する。生成物と元データを同じ公開単位に含める。

`data/lab-pages-manifest.json`は生成元のSHA-256を保持する。改行はLFへ正規化して比較し、Windowsと公開用チェックアウトの差を避ける。この記録はゲーム内の数値検証日を意味しない。

canonicalとサイトマップは既存の公開先`https://36odi.github.io/pokemon-unite-tracker/`に合わせる。未知の更新日をlastmodへ補わない。CSS・画像・計算画面のリンクは相対配置に対応する。
