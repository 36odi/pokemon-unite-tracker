# 回復・特性のレシオ反映（2026-10-11）

## 対応内容

- 既存の正本 `data/unitedb_ratios.csv` の数式列にある特性43成分（31種）をすべてラボへ反映した。取り込み済み9成分を保持し、未取り込み34成分を追加した。レシオ一覧・ステータス計算・ダメージ計算で共通の成分を使う。
- 数式のステータス係数が0でも、固定値やレベル補正があれば計算画面に表示する。ヌメルゴンのりゅうのはどうの回復、わざによる能力上昇、ユナイトわざの最大HP増加などが対象。
- ダメージ・回復・シールド・能力変化を区別する。回復・シールド・能力変化へ防御による軽減やエナジーアンプを適用しない。ギルガルドの「シールドフォルム」は能力上昇であり、シールド付与ではない。
- 攻撃速度上昇には%を表示する。能力変化は効果量を別表示し、実際のステータスへ自動加算しない。
- マッシブーンのきゅうけつの回復式は、与ダメージに対する割合。回復HP量として表示せず、レシオ一覧と計算画面に%と注意書きを付ける。実際の与ダメージなしに回復HPや回復補正を推定しない。
- ステータス計算の選択候補を、ダメージ計算と同じ「ステータスが収録済みの101種」にそろえた。既存データのあるストライクの特性も計算できる。
- 追加した特性は成分キーで出典へ接続し、再生成時の再追加・数値更新にも対応した。既存の1,851行とステータス・もちもの・メダルのデータは変更せず、全体は1,885行になった。

## 数式・出典の範囲

今回の出典は、プロジェクトで使用している既存のUnite-DB由来の正本CSV。最新の全ポケモン・全効果を外部資料で再監査した変更ではない。

**数式列にないHP割合・与ダメージ割合・追加条件は推測で補完しない。** 元資料に数式がない特性を「0」として新規登録しない。レシオ未収録と、効果がない状態を区別する。

ヌメルゴンのりゅうのはどうは固定部分のみで、減少HPに応じた回復を含まない注記を維持した。バシャーモの回復、ダダリンの残存シールドに応じた回復、スイクン・イベルタルの相手最大HPに応じた確定ダメージなど、今回の数式に含まれない部分は注記する。特性の成立やスタック数、能力変化の実ステータスへの反映、時間経過を自動再現するものではない。
