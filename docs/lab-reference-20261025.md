## 再発防止

`build_skills_from_unitedb.js` の入口を維持し、数値同期は `build_lab_skills_from_keys.js` へ分離。1,502の出典数値成分がそれぞれのキーで存在することを確認する。数式が同じという理由では統合しない。

既存行の対応は `data/lab-source-identities.json` に保存。未知の行、出典の欠落、CSVと原文メタデータの取得時点の不一致で停止する。文章中の効果は原文の根拠文が変われば再確認を要求する。再生成を2回行っても行や注記が増えないことを検査する。

元シート、対戦記録、メダルの保存データ、既存の計算条件は書き換えない。過去の計算条件は現在のデータで再計算し、従来のデータ版の差を知らせる仕組みを維持する。
