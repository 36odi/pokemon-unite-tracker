# ランク帯集計の修正（2026-10-07）

- クラス帯は記録した帯を使用。クラス帯の次の最初のレート記録も自身の帯を使用する。
- 同一シリーズのレート記録が続く場合だけ、直前のレートでマスター／レジェンドを判定する。
- battles.played_rank が指定された試合は訂正を優先。レート値は変更せず、次の試合の判定にも訂正を伝播させない。
- ランク未記録・記録漏れから開始時の帯を完全には復元できないため、訂正欄で補う。
- ゲストからアカウントへの移行でも訂正を保持する。DB列が未準備の場合は訂正のあるデータの移行を中止し、元データを残す。
