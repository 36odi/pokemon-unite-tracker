# レシオ一覧の表示整理（2026-09-30）

対象は `ratio.js` の一覧表示。計算用の `LAB_SKILLS`、数値、待ち時間、元CSVは変更しない。

## 重複して見えた成分

同じ式でも異なる条件のため、行の削除や数値による統合はしない。
正本CSVの `effect_label` とWikiの日本語説明を突き合わせて条件名を付けた。

|ポケモン|区別した条件|
|---|---|
|カメックス|しおふきの通常時／こうそくスピン中|
|バシャーモ|爆炎旋風拳／爆炎旋風脚。見出しも分割|
|マッシブーン|最初の範囲攻撃／HP割合が最も低い相手への追撃|
|ダダリン|パワーウィップの基本部分／錨の先端の追加ダメージ|
|ドラパルト|シャドーボールの命中／最後のマーク発動|
|ヌメルゴン|りゅうのはどうの中心／周囲、ぬめぬめ有無、アシッドボムの液体／突進|
|リーフィア|葉の行き／戻り、最初の跳躍／2回目の遠距離部分|
|ミミッキュ|ひっかくの突進／ツメの攻撃|
|アマージョ|トロピカルキックの通常時／じょおうのいげん発動時|
|バンギラス|げんしのちからの1回目／再使用時|
|ウーラオス|通常／衝突。漆黒の終拳と蒼流の舞踏の見出しも分割|

## 共通の整理

- 「通常攻撃」等の見出しと待ち時間の重複を減らす。
- ＋の条件・式・回数がすべて同じなら、式を再掲せず「表示している式と回数は通常版と同じ」と表示。未収録や部分式には適用しない。
- `Second Hit` が「初撃」になっていた成分を「2段目」に修正。
- 「範囲（6ヒット）」「0.5秒毎最大4回」「13回最大」等、別成分にも流用されていた旧ラベルから回数を切り離す。回数は既存の回数データによる別表示を使う。
- 英語混じりの説明を日本語化。タイレーツは「ヘイチョー」「ヘイ」「たてのじん」「はいすいのじん」「はへいのじん」にそろえる。
- ヌメルゴンの回復式は減少HPに応じた部分が元データに含まれないため、その点を明記する。アシッドボムの突進は表示式が1回分であることを明記する。

## 保守・検証

旧行には成分キーがないため、`RATIO_COMPONENT_LABELS` は旧名称・レベル・ラベル内の成分順を使用する。数値が等しくても別成分として保持する。成分数が変わった場合は条件名を当てはめず「条件の対応を要確認」とする。再生成時は元CSVの成分と照合して辞書・テストも確認する。

`node tests/ratio-labels.test.js` で全101匹の条件名重複、英語断片、元データ不変と代表的な条件を検証。
`node tests/ratio.browser.test.js` で＋の補完、別わざ名の分割、スマートフォン幅を検証。
