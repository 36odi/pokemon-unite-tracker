# ラボの日本語説明の統一（2026-10-09）

## 今回の変更

- `ratio-labels.js` の説明辞書をレシオ一覧・ステータス計算・ダメージ計算で共通利用する。計算画面に残っていた別の翻訳処理は削除した。
- 表示する成分の条件名、別名のユナイトわざ、注意書きを共通化。アブソルのつじぎりの2段目を「初撃」と表示していた問題も解消した。
- 全101種・1,851行から生成する429種類の説明を確認。「効果（条件・条件）」に区切りを揃え、「毎」「ヒットごと」は対象に応じて「1ヒットあたり」「1個あたり」等に整理した。3発ごとの周期など、意味が違うものは一律変換しない。
- 「クリーム毎（48 最大）」は「クリーム1個あたり・最大48個」、「4 ティック」は「継続ダメージ（全4回）」に変更。チャージの度合い、攻撃箇所、対象、個数・回数は保持する。
- 元のデータと計算式は変更しない。表示する行の選択も従来どおり。たとえばヌメルゴンのりゅうのはどうの回復行は、係数0の行を除外する既存仕様により、計算画面には引き続き表示されない。今回、全レシオ行を計算画面で表示できるようにしたわけではない。

日本語の意味はリポジトリ内 `data/unitedb_ratios.csv` の英語の成分名・説明と照合した。固有表現を追加照合した資料は、[オーダイルのキバの名称](https://wikiwiki.jp/poke-unite/オーダイル)、[ルカリオのしんそく後の攻撃](https://gamewith.jp/pokemon-unite/article/show/284297)。どちらも公式資料ではなく、名称・説明の補助確認として使用した。数値の最新性を再監査したものではない。

検証：日本語ラベル9,270項目、画面66項目、既存ロジック214項目、ラボ参照178項目、効果計算36項目、既存の計算画面37＋13項目が通過。全1,851行を3画面の表示処理に渡し、計算画面で表示対象となる行の説明・注意書きが共通辞書と一致することを確認した。390px幅で画面のはみ出しがないことも確認。外部通信を遮断したローカル検証で、実DBへの書き込みはない。

## 共通の整理

- 「通常攻撃」等の見出しと待ち時間の重複を減らす。
- ＋の条件・式・回数がすべて同じなら、式を再掲せず「表示している式と回数は通常版と同じ」と表示。未収録や部分式には適用しない。
- `Second Hit` が「初撃」になっていた成分を「2段目」に修正。
- 「範囲（6ヒット）」「0.5秒毎最大4回」「13回最大」等、別成分にも流用されていた旧ラベルから回数を切り離す。回数は既存の回数データによる別表示を使う。
- 英語混じりの説明を日本語化。タイレーツは「ヘイチョー」「ヘイ」「たてのじん」「はいすいのじん」「はへいのじん」にそろえる。
- ヌメルゴンの回復式は減少HPに応じた部分が元データに含まれないため、その点を明記する。アシッドボムの突進は表示式が1回分であることを明記する。

## 保守・検証

旧行には成分キーがないため、`RATIO_COMPONENT_LABELS` は旧名称・レベル・ラベル内の成分順を使用する。数値が等しくても別成分として保持する。成分数が変わった場合は条件名を当てはめず「条件の対応を要確認」とする。再生成時は元CSVの成分と照合して辞書・テストも確認する。

`node tests/ratio-labels.test.js` で全101匹の条件名重複、英語断片、元データ不変と代表的な条件を検証。
`node tests/ratio.browser.test.js` で＋の補完、別わざ名の分割、スマートフォン幅を検証。
